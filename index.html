Crear modelo usando una IA externa

Adjuntá el PDF en ChatGPT, Gemini, Claude u otra IA. El prompt extrae únicamente su diseño editorial: tamaño, márgenes, tipografías, jerarquías, espaciado y composición. Después pegá aquí el JSON.

Este prompt define el formato JSON que DOCULAB puede importar.
DOCULAB validará la estructura y cargará los componentes en el constructor. Después podés revisarlos y guardarlos.
PDF
Reconstruir un modelo desde un PDF

Subí un documento de referencia y la IA identificará su índice, jerarquías, secciones y patrones para convertirlos en componentes editables.

La extracción de texto sirve solo para detectar roles tipográficos; para analizar con precisión colores, márgenes y composición, usá el flujo de IA externa adjuntando el PDF original.
